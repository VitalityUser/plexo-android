What is Plexo Android?

Plexo Android is a revolutionary open-source multi-network download manager for Android designed to combine your Wi-Fi and 5G/4G Cellular data into a single aggregated high-speed pipeline.

Instead of letting your secondary internet connection sit idle, Plexo leverages Android's ConnectivityManager.requestNetwork API to keep both interfaces active simultaneously, splitting large files into multi-socket parallel streams across both networks to deliver up to 2x faster download speeds.

Frequently Asked Questions (FAQ)

How does Plexo download over Wi-Fi and Mobile Data at the same time?

Plexo uses Android's multi-network APIs to bind individual socket connections directly to specific network interfaces. Chunks 1–8 are routed via Wi-Fi while chunks 9–16 are routed via Mobile Data simultaneously, recombining the file in real-time.

How do I enable dual connections on my Android device?

Go to Android Settings > Developer Options and turn ON "Mobile data always active". Then turn on both Wi-Fi and Mobile Data. Plexo will display the ⚡ BONDED status.

Is Plexo Android free?

Yes! Plexo is 100% free, open-source under the MIT license, and contains no ads or tracking.
