Got Questions?

Frequently Asked Questions

Can I connect multiple Wi-Fi networks at once?

Phones physically contain only one Wi-Fi radio antenna, so connecting to two different Wi-Fi routers directly is impossible without dual-radio hardware. However, Plexo solves this by letting you bond Wi-Fi with USB-C Ethernet (via a USB-C adapter) and Bluetooth Tethering (from a second phone or hotspot), alongside 5G cellular for true multi-link aggregation.

How does Plexo combine multiple connections at the same time?

Android devices have separate physical network adapters for Wi-Fi, Cellular, Ethernet, and Bluetooth. Plexo requests Android's system to keep all adapters alive and binds parallel download chunks across each socket simultaneously.

Does Plexo Android require root?

No root is required. Plexo works on any standard Android smartphone or tablet running Android 8.0 (Oreo) through Android 15+.

Is Plexo safe and open source?

Yes. Plexo Android is completely open-source under the MIT license with all code publicly auditable on GitHub. It contains zero analytics, zero telemetry, and zero ads.
